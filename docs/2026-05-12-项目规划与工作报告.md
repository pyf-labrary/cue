## 一、项目定位

「Cue · 影视配乐入门」是一个**互动型教学站**，目标：让从未学过配乐的导演 / 编剧 / 内容创作者在不读乐理课本的前提下，建立"听 → 辨 → 用"的配乐直觉。

**第一性原则**：可听 > 可读。任何乐器名词必须能在 200ms 内播出来。

**三条主轴**：
1. **情绪 → 乐器**（顺向）："我要紧张感，谁来给我？"
2. **乐器 → 情绪**（反向）："这件乐器擅长讲什么？"
3. **场景 → 配置**（应用）："经典场景是怎么调度多轨的？"

### M3 场景拆解（已完成）
- 5 个首批场景，每个含手法 + 描述 + 用到的乐器（链回图鉴）+ 程序化合成的 MX/FX/NX 三轨 + 时间码注释：
  - **海里有东西**（《大白鲨》1975）— Ostinato 反复短句
  - **竹林独白**（《卧虎藏龙》2000）— Leitmotif 主题动机
  - **浴室戏**（《惊魂记》1960）— Stinger 一击式
  - **父亲离开**（《星际穿越》2014）— Pedal Tone 持续延音
  - **西西里葬礼**（《教父》1972）— Slow March 慢板进行曲
- 9 种手法标签 + 12 情绪标签的双重过滤
- MultiTrackPlayer 组件：5 条 lane（DX/MX/FX/NX/VO）+ 大圆 play/pause + 时间码 + 每条 lane 独立 M/S 按钮 + 播放头扫描 + annotation 时间轴磁贴 + 当前时间窗内笔记浮现
- `scenePlayer.ts` 单例 + 订阅模型，setTimeout 调度 + session 计数器解决 stop / seek / mute / solo 切换的精确性

### M3.5 AI 真录音 MX（已完成）
- 用 MiniMax music-1.5 生成 5 段场景器乐 mp3，落 `public/scenes/<slug>/mx.mp3`
- 总 7.3MB，¥成本约 7-15 元（一次性）
- `scenes.ts` 加 `mxAudio` / `mxAudioGain` 字段，所有 5 个场景填上
- `scenePlayer` 双路：检测到 `mxAudio` 时用 Howler 播放真录音 + 跳过合成 MX；FX/NX 仍走 Tone synth 叠加
- MultiTrackPlayer MX lane 显示连续长条 + `REC` 标签区分真录音
- Mute MX → `mxHowl.mute(true)` 立切；Solo MX → 合成 FX/NX 通过 `effectiveMuted` 跳过

### M3.6 时长对齐（已完成）
- MiniMax 忽视 prompt 中的时长提示，输出 31-73s 不等
- 解决：保留场景原始叙事时长（18-26s），ticker 到点强制 `mxHowl.stop()` + `cancelSynth()`，AI 多生成的后段丢弃
- 所有 lane 现视觉对齐到 scene 设计长度

### 关键模块设计

**`synth.ts` — 乐器音色统一层**
- `SAMPLERS` 表：17 件乐器 → Tone.Sampler URL map（每件 5-7 锚点，Sampler 内部按音高线性插值填补未录音）
- `RECIPES` 表：5 件无采样的乐器（timpani/taiko/celesta/synth-pad/pizzicato-strings）走纯合成
- 全局 FX bus：`Limiter(-3dB) ← Reverb(decay 2.6s, wet 22%) ← input Gain`，所有乐器统一过混响 + 限幅
- `playSynthPhrase(id)` 接口：setTimeout 调度 + session 计数器 → stop 干净不漏音
- 暴露 `resolveInstrument(id)` 给 scenePlayer 直接拿 sampler 句柄

**`scenePlayer.ts` — 多轨场景引擎**
- 单例 + 订阅模型：UI 用 `useScenePlayer()` hook 拿状态
- 检测 `scene.mxAudio` → Howler 路径；否则合成 MX 路径
- mute / solo 在两侧并行作用：MX 是 `mxHowl.mute(true)`；FX/NX 是 trigger 时检查 `effectiveMuted()`
- ticker：rAF 驱动，从 Howler.seek() 或 Tone.now() 读位置
- 硬截断：到 `scene.durationSec` 强制停所有源

**`MultiTrackPlayer.tsx` — UI**
- 5 条 lane 即使空也显示（教学透明性）
- mxAudio 模式下 MX lane 显示连续长条 + `REC` 标签；synth 模式显示离散事件块
- annotation 时间窗（±0.6s）触发笔记浮现
- 时间轴底部小磁贴可点击 seek

### 数据流

```
用户点 play
  ↓
scenePlayer.play()
  ↓
├─→ Howler.play()   ← 真录音 MX
└─→ setTimeout(...) ← 每个 fx/nx 事件
       ↓
     trigger time
       ↓
     check effectiveMuted(track)
       ↓ 通过
     resolveInstrument(id).sampler.triggerAttackRelease(...)
       ↓
     audio out → FX bus → reverb + limiter → destination
```

## 五、已知问题 / 待打磨

### 高优
1. **AI 录音质量参差**：MiniMax music-1.5 对小众情境（如 Psycho stinger）出片不稳。建议听过后挑出 1-2 条最不对劲的，针对性调 prompt 重生成（成本 ¥1-3/次）
2. **annotations 时间码可能与 AI 录音转折点不重合**：原始 annotation 设计基于合成 phrase；AI 出片自有起承转合，需用户回听对照后微调时间码
3. **FX/NX 合成层与 AI 录音里已有的同类层会叠加**：Jaws timpani 在录音里可能已存在，合成 FX 再敲一次会显得重。可选：FX/NX 在 mxAudio 场景里降低 vel，或彻底取消（信任 AI 单声道混音）

### 中优
4. **古琴 / 古筝 GM 替身仍然有"东亚乐器风味的西方采样"感**：要质感再上一档，C 方案——用 MiniMax music-1.5 生成 5 件代表 phrase 真录音盖住 Sampler 输出，参考场景 mxAudio 模式
5. **`/lessons` `/sandbox` `/glossary` 全是占位**
6. **没有移动端响应式打磨**：当前布局只在 ≥1280px 桌面端测过，手机会塌
7. **没有键盘快捷键**（空格 play/pause、左右箭头 seek）

### 低优
8. **首屏 fonts 加载延迟**：思源宋体 + Inter 从 Google Fonts 拉，国内打开第一次可能 1-2s 出字。可换 jsdelivr / 本地子集化
9. **Atlas 卡片的"代表 phrase" 试听按钮文案是 "试听"，乐器详情页的大按钮是 "代表 phrase"**：术语统一一下
10. **场景列表 Scenes.tsx 没有给 5 个场景配封面图**：现在是纯文字卡片，加 cinematic key art（即梦 i2i 生成）会更"电影感"

## 六、下一步规划（M4-M6）

### M4 入门五课 + 术语手册（建议 3-4 天）
- `/lessons/[1..5]`：线性引导，10-15 分钟一节，互动 > 阅读
- 第 1 课：五轨是什么——拖动音量条把一段戏从"只有对白"变到"全混"
- 第 2 课：音色 = 情绪载体——同一段旋律换 4 件乐器演一遍
- 第 3 课：三种配乐手法——under-score / source / hybrid
- 第 4 课：节奏与剪辑点——hit point / stinger / sting
- 第 5 课：你的第一段配乐——给一段 30s 无声片段，从 sandbox 拖音轨拼出
- `/glossary` 40 条术语手册，每条带 3s 演示音

可复用资产：existing samplers + scene 引擎；新组件是"任务式 widget"（拖动滑块、选乐器、对比 A/B）

### M5 配乐试听台 Sandbox（建议 3 天）
- 上传或选一段无声视频 ≤30s

- 导出 webm（mp4 转码不闭环，提示用户外部转）
- 复用 scenePlayer 引擎，扩展为可编辑模式
