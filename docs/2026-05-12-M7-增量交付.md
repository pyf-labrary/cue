## 二、技术架构变化

### 双引擎合一
M6 时 SceneDetail 用 `scenePlayer.ts`（~360 行），Sandbox/Lesson 用 `compositionPlayer.ts`。M7 把 `scenePlayer.ts` 整个删掉，MultiTrackPlayer 改成 `sceneToComposition()` 转 Scene → Composition 喂给 compositionPlayer。同时多出"在试听台打开"按钮 — 把当前场景 base64url 编码进 URL hash 跳到 Sandbox。

### 持久化 + 分享 URL
`src/lib/compositionShare.ts` — 提供 `encodeComposition` / `decodeComposition` / `loadFromStorage` / `saveToStorage` / `buildShareUrl` / `readShareFromHash` / `stripShareFromHash`。

- localStorage key 前缀 `cue:composition:`
- URL hash query 参数 `s=<base64url>` — HashRouter 友好
- Schema version `__v=1`，breaking change 时旧链接自动作废

Sandbox 与 Lesson L5 SandboxBeat 都接 ShareControls。Sandbox 还接 SceneDetail 来的 `?s=` URL 跳转（场景预填）。

### 视频上传 + webm 导出
`src/lib/recorder.ts` — 用 mixer AudioContext 把 Tone 与 Howler 两条 MediaStream 合并：

```
Tone.context.fxIn ─┐
                   ├→ Tone context: MediaStreamDestination →┐
                   ↓                                         ├→ mixerCtx.MediaStreamSource ─┐
   Howler.ctx.masterGain → Howler context: MediaStreamDest ─┘                                ├→ mixerCtx.MediaStreamDest → MediaStream(audio)
                                                                                              ↓
                                                                                          [merged audio track]
                                                                                              +
                                                                                          videoEl.captureStream().getVideoTracks()
                                                                                              ↓
                                                                                          MediaRecorder(video/webm;codecs=vp9,opus)
```

VideoPanel 支持 mp4/mov/webm 上传，与 compositionPlayer transport 同步播放/暂停/seek。导出 webm 边播边录。**前提**：用户至少播放过一次解锁 AudioContext。

### 实时频谱（log-spaced）
`src/lib/spectrum.ts` — 同时读 Tone.Analyser('fft', 128) + Howler.ctx.createAnalyser(fftSize=256)，**对数频率映射**到 32 视觉条（覆盖 ~344Hz–15.5kHz；DC bin 跳过；高频上界截到 90 bin 避免 nyquist 区静音）。组件 SpectrumStrip.tsx 用 rAF + 峰值衰减 (`decay -= 0.04/frame`) 渲染到 canvas。

挂在 Sandbox / Lesson Transport / MultiTrackPlayer transport 三处。

### 推迟音频图构建
M6 时 `setComposition` 立即创建 Tone.Sampler / Howl / FX bus 整链。问题：

- Chrome 看到 suspended AudioContext 被构造音频节点 → 每个节点一个 "AudioContext was not allowed to start" warning（jaws 场景 15 次）
- Howl 默认 `html5: true` 占 audio pool slot（默认 10 个），切几个场景就耗尽 → "HTML5 Audio pool exhausted"

M7 修法：

- setComposition 只 dispose 老 Howl + 存 comp，立即返回
- 首次 play() 进 status='loading'，`await ensureAudioStarted()`（用户手势已具备） → warm(samplers + howls) → startPlayback
- 二次以后 play() 走 warmedFor 快速路径
- 场景 MX Howl 从 `html5: true` 改成 `html5: false`（Web Audio buffer 模式），完全不占池
- `Howler.html5PoolSize` 10 → 32（Atlas 翻预览不耗尽）

### ScrubBar：DAW 风格
`src/components/audio/ScrubBar.tsx` — Pointer Events 统一 mouse/touch/pen。**关键**：拖动期间不实时打 seek（每帧 stop + reschedule 会堆叠音频 + 卡主线程），改成：

- pointerdown → 暂停（如果在播）+ 进 drag 态
- pointermove → 只更新本地 dragSec 状态
- pointerup → 一次 seek + 必要时恢复播放

### MiniMax 真乐器 demo
不替换 Sampler（MiniMax music-1.5 是整曲生成器无法做单音采样集）。给 erhu/guzheng/guqin/choir 各生成 12s 真演奏 demo（MiniMax 实际给 30-60s 不听 duration，ffmpeg 截 12s + 0.6s 淡出）。Atlas 单乐器页加第二个 PlayButton "听一段真乐器"。共 ~0.9 MB / 4 次调用 / ~¥6-12。

### 场景时间码 rescale
M6 时 5 个场景的 `durationSec` / annotation / fx / nx 时间码按合成 MX（24s 左右）设计；AI MX 实际 30-73s。M7 按真录音长度做了**线性缩放**：

| 场景 | 旧 dur | 真 MX | 缩放 |
|---|---|---|---|
| jaws | 26 | 56 | ×2.14 |
| crouching-tiger-bamboo | 22 | 41 | ×1.85 |
| psycho-shower | 18 | 31 | ×1.72 |
| interstellar-cooper-leaves | 26 | 73 | ×2.82 |
| godfather-funeral | 24 | 35 | ×1.47 |

每个场景的 scenes.ts 里有 `TIMING NOTE` 注释。线性缩放不一定精确（AI MX 不保证按比例 stretch），**Jaws / Interstellar 最容易错位，建议人工听一遍微调**。

### 导演笔记跨段保留
M6 时 annotation 用 `Math.abs(a.at - current) < 0.6` 过滤——1.2s 窗，看不清就消失。M7 改成"显示最近一条已触发的 annotation 直到下一条触发"，自然跟着剧情节奏停留。

## 五、关键决策

| 决策 | 原因 |
|---|---|
| ScrubBar 用 Pointer Events 而非 mouse + touch 分支 | 一份代码覆盖 mouse / touch / pen；touchstart 在某些浏览器是 passive 导致 preventDefault 失败 |
| 拖动只更新视觉、松手才 seek | 每帧 seek 触发 Howl.stop + reschedule，主线程 jank + 多次 howl.play 叠加产生重音 |
| setComposition 不预热音频图 | autoplay warning + html5 audio pool 耗尽都源于 mount 时构造节点；推迟到 play() 自然解锁 |
| Howl 改 html5:false（Web Audio buffer） | scene MX < 300KB，buffer 内存代价小；彻底跳出 html5 pool |
| 线性 rescale 场景时间码 | 真听一遍 ear-tune 需要 1-2h 集中工作；线性缩放是"差不多对"的便宜 first-pass |
| 真乐器 demo 不替换 Sampler | MiniMax music-1.5 是整曲生成器无法做单音库；deferred 到未来 |
| 频谱用对数频率映射 | 64 bin 线性 → 后半基本静音；对数 + 截到 90 bin 上界让 32 视觉条均匀负载 |
| 持久化用 base64url URL 而非 server-side gist | 站点纯静态 GH Pages 无后端；URL 1-3KB 够装一个 sandbox composition |
